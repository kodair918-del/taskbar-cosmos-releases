# Taskbar Cosmos

タスクバーで育てる、小さな宇宙の放置ゲーム（Windows 10 / 11）
A tiny idle universe that lives in your taskbar (Windows 10 / 11)

## ダウンロード

1. [いちばん新しい版](../../releases/latest) の `TaskbarCosmos_v〇〇.zip` をダウンロードします。
2. zip を右クリック →「すべて展開」して、中の `TaskbarCosmos.exe` をダブルクリックします。
3. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で開けます。

新しい版が出ると、ゲームの中に「新しい版があります」と出ます。「更新する」を押すだけで入れ替わります（セーブはそのまま）。

## Download

1. Get `TaskbarCosmos_vX.Y.Z.zip` from the [latest release](../../releases/latest).
2. Right-click the zip > "Extract All", then run `TaskbarCosmos.exe`.
3. If "Windows protected your PC" appears, click "More info" > "Run anyway".

When a new version is out, the game tells you and updates with one click (your progress is kept).
